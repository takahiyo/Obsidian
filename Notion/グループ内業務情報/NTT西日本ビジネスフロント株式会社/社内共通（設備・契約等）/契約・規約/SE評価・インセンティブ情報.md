【匠総合ランキング】

- 年間賞
	以下のポイントを算出し、SEの上位3名を表彰する
	販売支援粗利額：トップを500ポイントとし、以降順位に基づき1ポイントずつ減少
	ICT支援粗利額：トップを500ポイントとし、以降順位に基づき1ポイントずつ減少
	スキル把握：SA400ポイント、A375ポイント、B+350ポイント、B250ポイント、C/Dポイント無し
	上期下期2回の平均値をポイント加算する
	その他：通信環境確認シート年間獲得数（新規・更新）120件以上
- 期間賞(四半期毎)
	年間賞と同じ計算を四半期毎に行い、SEの上位3名を表彰する

| 評価期間 | 表彰時期予定 |
| --- | --- |
| 第1四半期(4-6月) | 8月 |
| 第2四半期(7-9月) | 11月 |
| 第3四半期(10-12月) | 2月 |
| 第4四半期(1-3月) | 5月 |

※上期スキル把握結果は第2四半期、下期スキル把握結果は第4四半期のみ適用する

その他：期間中の通信環境確認シート獲得数（新規・更新）30件以上

- 特別賞
	各期間の匠総合ランキング4位以下から、契約社員グレードA上位1名、グレードB上位1名を表彰する
