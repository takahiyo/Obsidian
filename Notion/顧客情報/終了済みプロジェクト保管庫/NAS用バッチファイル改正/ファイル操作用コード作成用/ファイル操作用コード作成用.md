# 目標設定

## 2023/12/18時点での要望

1. 「WeeklyCopy_Share」をバッファロー内へコピーして、
2. 「WeeklyCopy_Share」を「Share」とミラーリングして更新
3. バッファロー内の4週間分を超えるものを削除

## 最終的な行程

4. [WeeklyCopy_Share]をBuffaloHDD内にコピーする
	1. フォルダ構造案
		- BuffaloHDDのルートにバックアップ用フォルダを作成し、その中に日付フォルダを作成。その中にバックアップ時の[WeeklyCopy_Share]をミラーリングする
			- BuffaloHDD：[WeeklyCopy_Share_Backup]\[yyyymmdd]
5. OSpro内の、[SHARE]フォルダを[WeeklyCopy_Share]にミラーリングする
6. BuffaloHDD内、[WeeklyCopy_Share_Backup]内の日付フォルダを最新の4つ分だけ残して削除する
	2. ここまでの行程を最終的にタスクスケジューラで毎週土曜深夜に実行させる

| <br>バックアップ時 | BuffaloHDD<br>[WeeklyCopy_Share_Backup] | BuffaloHDD<br>[WeeklyCopy_Share_Backup] | OSpro4<br>[Share] | OSpro4<br>[WeeklyCopy_Share] |
| --- | --- | --- | --- | --- |
| フォルダ状況推移 | フォルダ内の[日付]フォルダを確認<br>最新の3つを残し削除<br>※タイムスタンプではなくフォルダ名でチェック | フォルダ内に[日付]フォルダを作成<br>[WeeklyCopy_Share]をミラーリング | 業務で運用しているまま | [Share]をミラーリング |
| フォルダ内イメージ | 2週前から4週前まで | 1週前から4週前まで | 現在 | 現在 |

- この順番に推移すれば、OSpro4内のバックアップはミラーリングで自然に1週間分になります
- 日曜毎に週番号が変わり、バックアップ行程完了時には日曜日になっていると考えれば、フォルダ内は以下のようになります
	- [Share]は運用フォルダで常に0週
	- [WeeklyCopy_Share]は-1週
	- [WeeklyCopy_Share_Backup]内には-2週から-5週

## 設計計画

- コピーする作業を先に完成させる
	- 削除作業は取り返しが付かない為
	- 最終的に削除の作業が完成するまでの間は、不要ファイルの削除は手動でやって頂く必要があります
- 可能な限りWindows標準の機能内で完成させる
	- コマンドプロンプト、PowerShellでの完成を目指します
		- 2023/12/18の試行結果によっては、削除はPython等別の手段を取る必要があるかもしれません
	- 現在はコマンドプロンプトをメインにしていますが、PowerShellへの移行を考えています
		- 対象になるフォルダが本来[\\192.168.1.250]形式のNASである為
		- コマンドプロンプトを使うには、現在の様に対象フォルダを[Y]ドライブに仮想化する必要があり、パソコンの買い替え時等に作業が複雑になる為

# テスト用コード置き場

## 以下は、PowerShellを使用したコード群です

試したいコードにマウスカーソルを乗せると、枠の右上に「コピー」ボタンが表示されます

クリップボードにコピーされますので、PowerShellを起動してCTRL+Vで貼り付けてください

警告が出た場合も、そのまま「強制的に貼り付け」れば実行されます

試したコードでエラーが出た場合は、スクリーンショットやテキストを下記報告用ページ内に貼り付けてください

[[報告用ページ]]

> [!note]+ [WeeklyCopy_Share]　を　BuffaloHDD[z:\WeeklyCopy_Backup]　内に日付フォルダを作成してコピーする
> ```javascript
> # バックアップ元の基本パスを設定
> $sourcePath = "\\192.168.1.250\WeeklyCopy_Share"
> 
> # バックアップ先の基本パスを設定
> $backupBasePath = "Z:\WeeklyCopy_Backup"
> 
> # バックアップ先のディレクトリを作成（既に存在する場合は何もしない）
> if (-not (Test-Path -Path $backupBasePath)) {
>     New-Item -Path $backupBasePath -ItemType Directory
> }
> 
> # 現在の日付を yyyymmdd 形式で取得
> $today = Get-Date -Format "yyyyMMdd"
> 
> # 今日の日付でサブディレクトリを作成
> $todayBackupPath = Join-Path -Path $backupBasePath -ChildPath $today
> if (-not (Test-Path -Path $todayBackupPath)) {
>     New-Item -Path $todayBackupPath -ItemType Directory
> }
> 
> # 今日のバックアップディレクトリにミラーリング
> robocopy $sourcePath $todayBackupPath /mir
> 
> # 処理完了メッセージ
> Write-Host "ミラーリング完了: $sourcePath -> $todayBackupPath"
> ```

> [!note]+ [WeeklyCopy_Share]　を　[Share]　に同期（ミラーリング）する
> ```javascript
> # コピー元とコピー先のパスを設定
> $sourcePath = "\\192.168.1.250\Share"
> $destinationPath = "\\192.168.1.250\WeeklyCopy_Share"
> 
> # コピー先のディレクトリが存在しない場合は作成
> if (-not (Test-Path -Path $destinationPath)) {
>     New-Item -Path $destinationPath -ItemType Directory
> }
> 
> # robocopy コマンドを使用してコピー元からコピー先にミラーリング
> robocopy $sourcePath $destinationPath /mir
> 
> # 処理完了メッセージ
> Write-Host "ミラーリング完了: $sourcePath -> $destinationPath"
> ```

> [!note]+ BuffaloHDD[z:\WeeklyCopy_Backup]　内の日付フォルダ名を参照し、最新の4つを残して削除する
※選択の為に参照するのは、タイムスタンプではなくフォルダ名にしてあります
> ```javascript
> # バックアップフォルダのパス
> $backupPath = "Z:\WeeklyCopy_Backup"
> 
> # バックアップフォルダ内のすべてのサブディレクトリを取得し、日付順にソート
> $directories = Get-ChildItem -Path $backupPath -Directory | 
>                Sort-Object -Property Name -Descending
> 
> # 最新の4つのディレクトリを除外し、残りを削除
> $directories | Select-Object -Skip 4 | ForEach-Object {
>     $dir = $_.FullName
>     Remove-Item -Path $dir -Recurse -Force
> }
> 
> # 処理完了メッセージ
> Write-Host "古いバックアップフォルダを削除しました。"
> ```
