# SA-W2の概要

| **用途と機能** | **拠点向けルーター機器の遠隔保守サービス「SACM」で利用できるルーター機器** |
| --- | --- |
| **提供形態** | **ハードウエア（インターネットエッジルーター）** |
| **ラインアップ中の位置付け** | **既存モデル「SA-W1」の後継。性能を2倍に高めたほか、イーサネット経由で給電するPoE受電機能や、5GHz帯の無線LAN機能を追加した** |
| **有線LAN** | **1000BASE-T×4ポート** |
| **有線WAN** | **1000BASE-T×1ポート（PoE受電機能付き）** |
| **無線LAN** | **2.4GHz（IEEE 802.11b/g/n）****5GHz（IEEE 802.11a/n/ac）****同時利用可** |
| **USBポート** | **USB 2.0 Type A×2ポート** |
| **スループット** | **約800Mビット/秒****IPsec VPN通信時は約200Mビット/秒** |
