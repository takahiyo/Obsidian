## 3. 各モデルの詳細評価と使い分け

### 第1位：Gemma 4 31B (free) 【最もおすすめ】

- **提供元**: OpenRouter
    
- **評価**: **★ ★ ★ ★ ★**
    
- **長所**:
    
    Googleのオープンウェイト最新世代。31Bという扱いやすいサイズ感でありながら、プログラミング構文の理解力、関数設計の堅牢性、日本語でのプロンプト理解が極めて高いレベルでまとまっています。
    
- **短所**:
    
    100万トークンのような超長大コンテキストは持たないため、巨大リポジトリの一括丸呑みには向きません。
    
- **結論**:
    
    **現在のDeepSeek無料枠の代用・併用先として最も堅実**。日々の開発における第一選択肢です。
    

### 第2位：Muse Spark 1.3 Free 【大規模プロジェクト向け】

- **提供元**: OpenCode Zen
    
- **評価**: **★ ★ ★ ★ ☆**
    
- **長所**:
    
    約100万トークンの巨大コンテキストとエージェント推論力。「調査→コード修正→テスト→修正」という一連の長いループを自律的にやり切る持久力は無料枠の中で圧倒的です。
    
- **短所**:
    
    推論ループにハマると作業完了まで時間がかかる点、そして「入力データがMetaのAI学習に利用される（Contributorライセンス）」という規約がある点です。
    
- **結論**:
    
    APIキーや機密情報を含まない個人の趣味開発・OSS検証であれば、最強クラスの無料エージェントです。
    

### 第3位：North Mini Code (free) 【小回り重視】

- **提供元**: OpenRouter
    
- **評価**: **★ ★ ★ ★ ☆**
    
- **長所**:
    
    コード生成に特化してパラメータが調整されているため、TypeScript、Python、Goなどの基本文法に忠実で、余計な前置きを省いた的確なコードブロックを返します。
    
- **短所**:
    
    パラメータが小型（Mini）のため、アーキテクチャ全体に影響する複雑な依存関係の解決や抽象度の高い設計指示では混乱することがあります。
    
- **結論**:
    
    「この関数をテスト付きで書いて」「このCSSレイアウトを直して」といった、スコープが限定された局所的タスクに最適です。
    

### 第4位：Nemotron 3.5 Lightning (Free) 【速度重視】

- **提供元**: OpenCode Zen / OpenRouter
    
- **評価**: **★ ★ ★ ☆ ☆**
    
- **長所**:
    
    NVIDIAの最適化技術が注ぎ込まれており、文字通り「電光石火（Lightning）」の超高速ストリーミングで出力されます。
    
- **短所**:
    
    複雑な文脈を深読みする能力（Reasoning）は上位モデルに劣り、思考の浅さによる初歩的バグが混ざることがあります。
    
- **結論**:
    
    「このエラーメッセージの意味を教えて」「正規表現をサッと作って」など、速度優先の壁打ち用途に向いています。
    

### 第5位以下（特殊・注意枠）

- **MiMo V2.5 Free**:
    
    マルチモーダル推論向け。コードのロジック構築力自体は標準的ですが、画面デザインの相談などには役立ちます。
    
- **Free Models Router**:
    
    その時点でレートリミットに余裕がある無料モデルへ自動で振られます。何が当たるか分からないため、コーディングの精度にムラが出やすく、常用はおすすめしません。
    
- **Ling 3.0 Flash (Fin / Sante)**:
    
    それぞれ「金融（Fin）」や「健康・医療（Sante）」に特化したファインチューニングが施されており、汎用プログラミング用としては能力を十全に発揮できません。
    
- **LFM2.5 - 2.6B / Laguna S 2.1**:
    
    パラメータが小さすぎるため、OpenCodeのように「ファイル全体を読み込み、差分を計算して安全に適用する」といった高度なエージェント運用をさせると、ファイル破壊やシンタックスエラーのリスクが高くなります。
    

## 4. 今後の推奨使い分けフロー

現在の「普段はDeepSeek無料枠、重い時だけOpenRouter従量課金」という運用に、今回の無料リストを組み込む場合の最適ルートです。

```
【普段の軽微な修正・関数作成】
  → Gemma 4 31B (free) または North Mini Code (free)
       ↓
【巨大リポジトリ・複数ファイル横断の自律作業（※機密情報なし）】
  → Muse Spark 1.3 Free
       ↓
【DeepSeek無料枠が混雑・エラーで落ちている時のバックアップ】
  → Gemma 4 31B (free)
       ↓
【どうしても通らない難解バグ・本番設計（数ヶ月に数回の課金）】
  → OpenRouter従量課金（Claude 3.7 Sonnet / Fable 5.1）
```
