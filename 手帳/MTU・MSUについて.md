MTU：Maximum Transfer Unit

IPベースの考え方

一度に送信できる最大のデータ量。IP通信の場合、MTUはIPヘッダを含むIPパケットの最大長を表し、レイヤ2以下のヘッダやフッタは含まない

MSS：Maximum Segment Size

TCPベースの考え方

TCPヘッダを含めない最大サイズを指す。NW機器ではなく、クライアントやサーバー等のホスト端末に設定が入っている

TCPのデータを含むイーサネットフレームの例

|   |   |   |
|---|---|---|
||←　この部分の最大長をMTUと呼ぶ　→||
|イーサネットヘッダ（14バイト）|IPヘッダ（20バイト）|TCPヘッダ（20バイト）|
||||

※FCSはイーサネットのフレームの一部である

イーサネットの最大サイズは規格上1518バイト。ここからイーサネットヘッダとFCSを除いた1500バイトが大抵の機器のインターフェースにおいてMTUのデフォルト値になっている

※新しい規格であるJumboフレームを使用すると9000バイト以上のデータを扱える

また、各端末のMSSは大抵、MTUからIPヘッダとTCPヘッダを除いた1460バイトがデフォルト値になっている

**代表的なMTU**

|   |   |   |
|---|---|---|
|インターフェース|MTU（単位：バイト）|備考|
|イーサネット|1500||
|フレッツ・VPNプライオLAN|1444|網側の指定|
|PPPoEセッション|PPPoEセッションを張るインターフェースのMTU-8|例）イーサネット上の場合：1500-8=1492|
|PPPoEセッション（ネクスト回線上）|1454|網側の指定|
|PPPoEセッション（プレミアム回線上）|1438|網側の指定|
|IPIPトンネル|IPIPトンネルを張るインターフェースのMTU-20|例）プライオ上の場合：1444-20-1424|
