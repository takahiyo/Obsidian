「Windowsパソコン等にSMB送信スキャンできない」お問い合わせが増えています ｜お客様マイページ｜大塚商会

■現象

複合機からWindowsパソコン等にSMBでスキャン送信できない

■対象

Windows 7、WindowsServer 2008 R2、WindowsServer 2008

■原因

2019年1月9日にMicrosoft社より公開された、WindowsUpdateによるセキュリティ更新プログラムが影響

【Windows7・Windows Server 2008 R2】

・Windows 7向け セキュリティ マンスリー品質ロールアップ（KB4480970）

・Windows用セキュリティ更新プログラム（KB4480960）

【Windows Server 2008】

・Windows Server 2008向け セキュリティマンスリー品質ロールアップ（KB4480968）

・Windows用セキュリティ更新プログラム（KB4480957）

■対処方法

2019年1月12日にMicrosoft社より、修正更新プログラムが公開されました。

お使いの環境に適用いただくことで不具合が解消されます。

●設定手順（よくあるお問い合わせ）

[複合機] KB4480970で発生する不具合の対策手順

https://faq.mypage.otsuka-shokai.co.jp/app/answers/detail/a_id/299512

●補足：Windows7パソコンの場合

不具合を修正するための更新プログラム（KB4487345）が公開されています。この更新プログラムはWindows Updateでは自動配信されておらず、Microsoft Update Catalog から手動でファイルをダウンロードしてインストールする必要があります。

Windows7 64/32でファイルが分かれています。

・Microsoft Update Catalog

https://www.catalog.update.microsoft.com/Search.aspx?q=KB4487345

●補足：WindowsServer2008 の場合

不具合を修正するための更新プログラム（KB4487354）が公開されています。
