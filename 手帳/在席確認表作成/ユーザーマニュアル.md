# 管理者マニュアル

1. ログイン
	- 営業所を選び、管理者パスワードを入力して下さい
		- 名古屋中央営業所
		- NagoChuAdmin116
2. 在席確認表
	- ユーザーと同じ操作は全てできます
	- 画面上部に「管理」ボタンが表示されます
3. 管理
	1. CSVエクスポート・インポート
		- 現在の名簿をCSVで出力します
		- CSVの列内容
            
			- グループ番号、グループ名、グループ内番号、ユーザーID、名前、内線番号、ステータス、戻り時間、備考
            
			|   |   |   |
			|---|---|---|
			|グループ番号|表示されるパネルグループはここで指定します||
			|グループ名|パネルに表示される名前です。グループ内の全員に必要です||
			|表示順|パネル内では、行の順ではなく、表示順の数字を見ています||
			|id|一意の英数字。ランダムで採番されますが、社員番号にしても良いです||
			|氏名|||
			|内線|||
			|ステータス|取り込み時点で指定できますが、あまり意味はありません||
			|戻り時間|同上||
			|備考|同上||
            
4. 拠点名の変更
	- ログインしている拠点の名前を変更できます
		- 画面上では後ろに「在席確認表」と追加されます
5. 拠点パスワードの変更
	- ユーザーパスワードと管理者パスワードを変更できます
	- 片方だけを変更する場合は、変更しない側は空白のままで良いです
6. メニュー設定
	- ステータスや備考のメニューを変更できます
	- もう少し分かりやすくする予定なので、当面は直接言ってもらった方が良いです
