仕様書（Ver 1.434_F7）
1. 概要

本システムは、拠点単位の在席状況を グループ（チーム）ごとのパネル で表示・編集する。

データはサーバと 約2秒ごとに双方向同期。CSVで名簿入出力可能。

役割は user / officeAdmin / superAdmin。マニュアルと管理機能は役割で出し分け。

2. UI仕様
2.1 盤面レイアウト

最大3列のレスポンシブグリッド。画面が狭いとカード表示へ自動切替。

グループジャンプ（ヘッダのタイトルボタン）で任意パネルへスクロール。

2.2 行構成と編集可否
項目	可否	備考
氏名	表示のみ	名簿（設定）由来
内線	表示のみ	編集不可
ステータス	変更可	メニューは設定（JSON）由来／既定：在席, 外出, 会議, テレワーク, 休み
戻り時間	条件付き	外出／会議の時のみ有効、07:00～22:00 の30分刻み
備考	入力可	テキスト＋プルダウン候補（直出／直帰／直出・直帰／空）。自由入力も可
2.3 ステータス連動

ステータスが「外出／会議」

戻り時間セレクトが有効化。未入力の場合、赤枠＋ヒント で入力を促す。

ステータスが「在席／テレワーク／休み」

戻り時間は自動で空 にする。

備考 は「候補（直出／直帰／直出・直帰）から選んでいた場合のみ空に」。
自由入力の文字列は保持（リセット対象外）。

2.4 行の色分け

在席：標準

外出：淡いオレンジ（左端オレンジ帯）

会議：淡いブルー（左端ブルー帯）

テレワーク：淡いパープル（左端パープル帯）

休み：淡いレッド（左端レッド帯）

2.5 ヘッダの検索／絞り込み

氏名フィルタ：入力と同時に部分一致で表示行をフィルタ。

ステータスフィルタ：プルダウンに 現時点の人数を併記（例：会議（5））。

氏名・ステータスの AND 条件でフィルタ。空にすると全件表示。

2.6 マニュアル

ヘッダの「マニュアル」ボタンでモーダル表示。

ユーザー／管理者 で表示内容を出し分け。

仕様（本書）に基づく内容で更新済み。

3. 名簿／CSV仕様

ヘッダ固定・日本語：
グループ番号, グループ名, 表示順, id, 氏名, 内線, ステータス, 戻り時間, 備考

読み込み時、空IDは採番される。表示順は数値昇順。

ステータス／戻り時間／備考は取り込み時点の初期値として反映可能。

エクスポートはExcel対策として UTF-8 BOM を付与。

4. メニュー設定（JSON）

例（既定）：

{
  "timeStepMinutes": 30,
  "statuses": [
    { "value": "在席", "class": "st-here" },
    { "value": "外出", "requireTime": true, "class": "st-out" },
    { "value": "会議", "requireTime": true, "class": "st-meeting" },
    { "value": "テレワーク", "class": "st-remote" },
    { "value": "休み", "class": "st-off" }
  ],
  "noteOptions": ["直出", "直帰", "直出・直帰"]
}


requireTime: true のステータスでは戻り時間を 促す（未入力時に強調表示）。

5. 同期／保存

サーバと 約2秒 間隔でGETポーリング。更新（set）は行単位でデバウンス送信。

ローカルに localStorage で状態を保持（拠点＋設定更新番号でキー分離）。

IME中は備考欄の送信を一時停止。フォーカスアウト等で送信再開。

6. 認証・権限

通常ログイン：拠点＋パスワード。

スーパー管理者：Nonce＋HMAC（追加認証）。

権限により管理機能／拠点操作が変化。

7. 管理機能

CSVエクスポート／インポート（日本語固定ヘッダ必須）

拠点名変更／パスワード変更

拠点の追加・削除（superAdmin）

メニュー設定（JSON）編集

8. アクセシビリティ

列見出しの代替ラベル（sr-only）

ステータス依存で戻り時間未入力時は aria-invalid 付与＋視覚ヒント

9. 既知の仕様・制約

同一セルの同時編集は 最後に確定した編集が勝つ。

戻り時間は 07:00～22:00 の範囲外は選択不可（分解能は設定の timeStepMinutes に従う）。

備考の「空白」相当は空文字（nullではなく空文字として保存）。

ロードマップ
A. 直近（高優先）

外出／会議の「未入力ブロック」オプション

現状は“促し”のみ。設定で「未入力は保存不可」に切替できるようにする（管理メニューのトグル追加）。

フィルタの保持

ページ再表示・他端末でも、ユーザーの最終フィルタ（氏名／ステータス）をローカル保存して復元。

人数カウントの細分化

グループパネルの見出しにも各ステータス人数のサマリを表示（任意切替）。

B. 中期（中優先）

氏名ジャンプの強化

先頭文字インデックス（五十音）やオートスクロールで対象行へフォーカス。

管理UIの利便性

CSV取り込み時のプレビュー＆差分表示、バリデーション詳細（時刻範囲・未知ステータス警告）。

アクセシビリティ拡充

キーボード操作（↑↓でステータス、←→で時刻ステップなど）、フォーカスリングの最適化。

C. 低優先

拠点ごとの色テーマ／ステータス名カスタムのプリセット保存

操作ログの軽量監査エクスポート（だれが／いつ／何を）

パフォーマンス最適化（行数が数千件のときの仮想スクロール検討）

function ensureTimePrompt(tr){
  if(!tr) return;
  const statusEl = tr.querySelector('select[name="status"]');

  const timeEl   = tr.querySelector('select[name="time"]');
  if(!(statusEl && timeTd && timeEl)) return;

  const needs = requiresTimeSet.has(statusEl.value);
  const empty = !timeEl.value;
  // 促し表示
  if(needs && empty){
    timeTd.classList.add('need-time');
    timeEl.setAttribute('aria-invalid','true');

      hint = document.createElement('span');

  }else{
    timeTd.classList.remove('need-time');
    timeEl.removeAttribute('aria-invalid');
    const hint = timeTd.querySelector('.time-hint');
    if(hint) hint.remove();
  }
}

function applyFilters(){
  const nameQ = (filterName.value||"").trim();
  const statQ = (filterStatus.value||"").trim();
  const nameRe = nameQ ? new RegExp(nameQ.replace(/[.*+?^${}()|[\]\\]/g,'\\$&')) : null;

  board.querySelectorAll('tbody tr').forEach(tr=>{

function updateStatusFilterCounts(){
  // 現在の人数を集計（全件ベース）
  const totalRows = board.querySelectorAll('tbody tr').length;
  const counts = new Map();
  STATUSES.forEach(s=>counts.set(s.value,0));
  board.querySelectorAll('tbody tr').forEach(tr=>{
    const st = tr.dataset.status || tr.querySelector('select[name="status"]')?.value || "";
    if(!counts.has(st)) counts.set(st,0);
    counts.set(st, counts.get(st)+1);
  });
  const cur = filterStatus.value;
  filterStatus.innerHTML = '';
  // 全て（合計）
  const optAll = document.createElement('option');
  optAll.value = '';

  filterStatus.appendChild(optAll);

  STATUSES.forEach(s=>{

    o.value = s.value;
    o.textContent = `${s.value}（${counts.get(s.value)||0}）`;
    filterStatus.appendChild(o);
  });
  // 既存選択を保持（無ければ全て）
  const exists = (cur==='' || STATUSES.some(x=>x.value===cur));
  filterStatus.value = exists ? cur : '';
}

function wireEvents(){
  // IME対策
  board.addEventListener('compositionstart', e => { const t=e.target; if(t && t.dataset) t.dataset.composing='1'; });
  board.addEventListener('compositionend',   e => { const t=e.target; if(t && t.dataset) delete t.dataset.composing; });

  board.addEventListener('focusin',  e => { const t=e.target; if(t && t.dataset) t.dataset.editing='1'; });
  board.addEventListener('focusout', e => { const t=e.target; if(t && t.dataset) delete t.dataset.editing; });

  board.addEventListener('input', (e)=>{
    const t = e.target;
    if(!(t && t.name)) return;
    const tr = t.closest('tr'); if(!tr) return;
    const key = tr.dataset.key;
    if(t.name === 'note'){ debounceRowPush(key); } /* extは表示専用 */
  });

  board.addEventListener('change', (e)=>{
    const t = e.target;
    if(!(t && t.name)) return;
    const tr = t.closest('tr'); if(!tr) return;
    const key = tr.dataset.key;

    if(t.name === 'status'){
      const timeSel = tr.querySelector('select[name="time"]');
      const noteInp = tr.querySelector('input[name="note"]');
      toggleTimeEnable(t, timeSel);

      // ステータスでクリア：time は 在席/テレワーク/休み で必ず空に
      if(CLEAR_TIME_ON_SET.has(t.value) && timeSel){ timeSel.value = ''; }

      // 備考は「候補から選んでいた場合のみ」空に（自由入力は保持）
      if(CLEAR_TIME_ON_SET.has(t.value) && noteInp){
        const val = (noteInp.value||'').trim();
        if(val==='' || NOTE_PRESETS.has(val)){ noteInp.value=''; }
      }

      // 外出/会議 → 戻り時間を促す
      if(requiresTimeSet.has(t.value)){
        ensureTimePrompt(tr);
        toast('外出/会議では戻り時間の選択をお願いします');
      }else{
        ensureTimePrompt(tr); // クリア側も実行して外す
      }

      recolor();
      updateStatusFilterCounts();
    }

    if(t.name === 'time'){
      // 時間選択で促しを外す/付け直す
      ensureTimePrompt(tr);
    }

    debounceRowPush(key);
  });

  // フィルタイベント
  filterName.addEventListener('input', applyFilters);
  filterStatus.addEventListener('change', applyFilters);
}

function parseCSV(text){
  const out=[]; let i=0,row=[],field='',inq=false;
  function pushField(){ row.push(field); field=''; }
  function pushRow(){ out.push(row); row=[]; }
  while(i<text.length){
    const c=text[i++];
    if(inq){
      if(c=='"'&&text[i]=='"'){ field+='"'; i++; }
      else if(c=='"'){ inq=false; }
      else field+=c;
    } else {
      if(c===','){ pushField(); }
      else if(c=='"'){ inq=true; }
      else if(c=='\n'){ pushField(); pushRow(); }
      else if(c=='\r'){ }
      else field+=c;
    }
  }
  if(field!=='') pushField();
  if(row.length) pushRow();
  return out;
}

/* ========== Nonce / HMAC ========== */
function issueNonce_(cache){
  const n = Utilities.getUuid().replace(/-/g,'');
  cache.put(KEY_PREFIX+'nonce:'+n, '1', NONCE_TTL_SEC);
  return n;
}
function consumeNonce_(cache, nonce){
  const k = KEY_PREFIX+'nonce:'+String(nonce||'');
  const hit = cache.get(k);
  if(!hit) return false;
  cache.remove(k);
  return true;
}
function getSuperSecret_(){
  const p = PropertiesService.getScriptProperties();
  const salt   = p.getProperty(PROP_SUPER_SALT);
  const keyB64 = p.getProperty(PROP_SUPER_KEY_B64);
  if(!salt || !keyB64) return null;
  return {salt, keyB64};
}
function hmacVerifyWithStoredKey_(nonce, hmacIn){
  const secret = getSuperSecret_(); if(!secret) return false;
  const clientB64 = String(hmacIn||'').replace(/ /g, '+');  // 念のため救済
  if(!clientB64) return false;

  const valueBytes = Utilities.newBlob(String(nonce)).getBytes();
  const keyBytes   = Utilities.base64Decode(secret.keyB64);
  const sigBytes   = Utilities.computeHmacSha256Signature(valueBytes, keyBytes);
  const serverB64  = Utilities.base64Encode(sigBytes);

  if(serverB64.length !== clientB64.length) return false;
  let ok = 0; for(let i=0;i<serverB64.length;i++){ ok |= (serverB64.charCodeAt(i) ^ clientB64.charCodeAt(i)); }
  return ok === 0;
}

    // 1) HMAC（super）
    if(nonce && hmac){
      if(!consumeNonce_(cache, nonce)) return json_({error:'unauthorized'});
      if(!hmacVerifyWithStoredKey_(nonce, hmac)) return json_({error:'unauthorized'});
      const token = Utilities.getUuid();

      return json_({token, exp:TOKEN_TTL_MS, office, officeName:offs[office].name, role:'superAdmin'});

        setToken_(prop, token, office, 'officeAdmin');
        return json_({token, exp:TOKEN_TTL_MS, office, officeName:offs[office].name, role:'officeAdmin'});

    props.setProperty('presence:SUPER_KEY_B64_BAK_'+stamp, oldKey);
    props.setProperty('presence:SUPER_LAST_ROTATED_AT', ''+now_());

    return json_({ok:true});
  }

  return json_({error:'unknown_action'});
}

//    既存を置換してデプロイしてください。GASがHTMLを返してもJSONで包んで返す安全版。

export default {
  async fetch(request) {
    const ALLOW = [
      'https://takahiyo.github.io',
      'https://takahiyo.github.io/whereabouts_TEST'
    ];
    const origin = request.headers.get('Origin') || '';
    const cors = {
      'Access-Control-Allow-Origin': ALLOW.includes(origin) ? origin : 'https://takahiyo.github.io',
      'Vary': 'Origin',
      'Access-Control-Allow-Methods': 'POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type',
      'Access-Control-Max-Age': '600'
    };

    if (request.method === 'OPTIONS') {
      return new Response(null, { status: 204, headers: cors });
    }
    if (request.method !== 'POST') {
      return new Response(JSON.stringify({ error: 'method_not_allowed' }), {
        status: 405, headers: { ...cors, 'Content-Type': 'application/json' }
      });
    }

    // ★ あなたの GAS /exec URL（最新デプロイの /exec）
    const GAS_URL = 'https://script.google.com/macros/s/AKfycbw6WHnnrQaQGJsWXSgrs6D2m9Uc2g6Pyf_NY1b_WCx80k2U-OXqPoshhzCYe7y4WtAJ/exec';

    // 受信ボディをパラメータ化
    let params = new URLSearchParams();
    try {
      const ct = (request.headers.get('Content-Type') || '').toLowerCase();
      if (ct.includes('application/json')) {
        const obj = await request.json().catch(() => ({}));
        Object.entries(obj || {}).forEach(([k, v]) => params.append(k, String(v)));
      } else if (ct.includes('application/x-www-form-urlencoded')) {
        const fd = await request.formData();
        for (const [k, v] of fd.entries()) params.append(k, String(v));
      } else {
        // 想定外はテキスト→URLSearchParamsとして試行
        const txt = await request.text();
        new URLSearchParams(txt).forEach((v, k) => params.append(k, v));
      }
    } catch (err) {
      return new Response(JSON.stringify({ error: 'bad_request', message: String(err) }), {
        status: 400, headers: { ...cors, 'Content-Type': 'application/json' }
      });
    }

    // GASにPOST
    let upstream;
    try {
      upstream = await fetch(GAS_URL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
        body: params
      });
    } catch (err) {
      return new Response(JSON.stringify({ error: 'upstream_fetch_failed', message: String(err) }), {
        status: 502, headers: { ...cors, 'Content-Type': 'application/json' }
      });
    }

    // 常に JSON で返す（GASがHTMLでも包む）
    const text = await upstream.text();
    const type = (upstream.headers.get('content-type') || '').toLowerCase();
    if (type.includes('application/json')) {
      return new Response(text, {
        status: upstream.status,
        headers: { ...cors, 'Content-Type': 'application/json' }
      });
    }
    // JSONでない→短いダンプをJSONに包む
    return new Response(JSON.stringify({
      error: 'upstream_not_json',
      status: upstream.status,
      preview: text.slice(0, 400)  // 先頭だけ返す（デバッグ用）
    }), {
      status: 502, headers: { ...cors, 'Content-Type': 'application/json' }
    });
  }
}
