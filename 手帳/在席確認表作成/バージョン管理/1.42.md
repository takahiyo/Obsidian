# 在席確認表 仕様書（Ver.1.41 → Ver.1.42）

## 1. 更新内容（差分サマリ）

### 1) セキュリティ／認証

* **スーパー管理者ログイン方式を刷新**

  * 1.41：ソース直書きの固定パスワード比較（`SUPER_ADMIN_PASSWORD`）。
  * 1.42：**HMAC 方式（パスワードは送らない）**。

    1. `getNonce` で **nonce** と **salt** を取得
    2. クライアントで `key = SHA256(salt + password)` を作成
    3. `hmac = HMAC-SHA256(nonce, key)` を送信
    4. サーバは保存済みの `key`（Base64）で検証
* **スーパー管理者の秘密はスクリプトプロパティに保存**

  * `presence:SUPER_SALT` / `presence:SUPER_KEY_B64`
  * 初期投入は **RUN-ONCE 初期化ラッパー関数**で1回だけ実行。以後は**関数を削除**して運用。
* **ノンス運用**

  * 使い捨て・**TTL 3分**・再利用不可。
* **API 変更（super 動作）**

  * 1.41 の `superPw=...` 再認証を廃止。
  * 1.42 では **`nonce` + `hmac`** を要求（`setConfigFor` / `setFor` / `deleteOffice` / `setOfficePassword` 等）。
* **HMAC 実装を厳格化**

  * GAS の `Utilities.computeHmacSha256Signature` を **byte\[]/byte\[]** で統一。
  * Base64 は **標準（`+/=`）** 固定。受信時の `+` → 空白問題は自動補正。

### 2) クライアント（フロント）

* **スーパー管理者ログインの実装**

  * `getNonce` → WebCrypto（`crypto.subtle`）で鍵生成 → `login?nonce&hmac` を送信。
  * `crypto.subtle` が使えない環境では **スーパー管理者はログイン不可**（通常/拠点管理者は従来どおり PW ログイン）。
* **メッセージ／エラーハンドリングの更新**

  * `no_super_secret`・`super_hmac_required`・`super_hmac_invalid` に対応。
* **既存機能は互換維持**

  * 一般ユーザ／拠点管理者の **PW ログインは従来どおり**。
  * 在席データ同期／名簿反映／自動バックアップ等は仕様そのまま。

### 3) サーバ（GAS）

* **新規エンドポイント**：`action=getNonce`（nonce & salt 返却）
* **`login` の仕様変更**

  * `nonce`+`hmac` がある場合：**super** として認証
  * `password` がある場合：`adminPassword` → **officeAdmin**、`password` → **user**
* **管理APIの再認証方式を HMAC に統一**

  * `setConfigFor` / `setFor` / `deleteOffice` / `setOfficePassword` などで、super の場合は **nonce/hmac 必須**。
* **バックアップ挙動は継続**

  * `setConfigFor`（CSV 等）と `deleteOffice` 実行前に、Drive へ JSON/CSV を**自動バックアップ**。
* **その他**

  * 旧 `setConfig`（`adminPw` を使う旧互換）は温存（自拠点のみ）。
  * `publicListOffices` は継続提供（未ログインで拠点選択用）。

## 2. 全体の仕様（Ver.1.42）

### 2.1 用語／役割

* **Office（拠点）**：名簿と在席データの論理区分。
* **Role（役割）**

  * `user`：在席データの参照・自己入力
  * `officeAdmin`：自拠点の管理（名簿編集、PW 変更、在席一括更新 等）
  * `superAdmin`：全拠点の管理（追加／削除／名変更／一括編集 等）

### 2.2 データ保管（Script Properties / Cache）

* 在席データ：`presence-board-<office>`
* 名簿（v2）：`presence-config-<office>`
* 拠点一覧：`presence:OFFICES_JSON`
* スーパー管理者秘密：`presence:SUPER_SALT` / `presence:SUPER_KEY_B64`
* キャッシュ：ScriptCache（データ/名簿は最長 20 秒）

### 2.3 トークン

* Web アプリの `login` 成功で**セッショントークン**発行

  * 期限：**1時間**（`renew` でスライド延長）
  * ScriptProperties に `tok_<token>`（有効期限）、`toff_<token>`（拠点）、`trole_<token>`（役割）

### 2.4 名簿スキーマ（v2）

```json
{
  "version": 2,
  "updated": 1710000000000,
  "groups": [
    {
      "title": "営業1課",
      "members": [
        {"name": "山田太郎", "ext": "1234", "id": "pabc123"}
      ]
    }
  ]
}
```

* `id` はサーバで正規化・重複排除して付与／維持。

### 2.5 API（JSONP, `callback` 必須）

#### 公開API（未ログイン）

* `action=publicListOffices`
  返却：`{ offices:[{id,name}] }`
* `action=getNonce`
  返却：`{ nonce, salt }`（※super 秘密未設定時は `{error:"no_super_secret"}`）

#### 認証

* `action=login&office=...&nonce=...&hmac=...` → **superAdmin**

* `action=login&office=...&password=...`

  * `password == adminPassword` → **officeAdmin**
  * `password == password` → **user**

* 返却：`{token, exp, office, officeName, role}` または `{error:"unauthorized"}`

* `action=renew&token=...` → `{ok:true, exp}`

#### 通常ユーザAPI（トークン拠点のみ）

* `get` / `set`（在席データ）
* `getConfig`（名簿）
* 旧互換 `setConfig`（自拠点 + adminPw）

#### 管理API

* `listOffices`：super=全拠点、officeAdmin=自拠点
* **指定拠点系**

  * `getFor`, `setFor`, `getConfigFor`, `setConfigFor`, `renameOffice`, `addOffice`, `deleteOffice`, `setOfficePassword`
  * **super の場合**：`nonce`+`hmac` **必須**

    * エラー：`super_hmac_required` / `super_hmac_invalid`
  * `setConfigFor`/`deleteOffice` は実行前に**自動バックアップ**

#### エラーコード

* `unauthorized`：トークン不正／PW 不一致／ノンス失効等
* `no_super_secret`：RUN-ONCE 未設定
* `super_hmac_required` / `super_hmac_invalid`：super 再認証エラー
* `no_office` / `forbidden` / `bad_config` / `too_large` など従来コード

### 2.6 フロント挙動（1.42）

* **ログイン**

  1. 拠点選択 → PW 入力
  2. `getNonce` 成功なら HMAC 計算して `login?nonce&hmac` 送信
  3. 失敗時／通常権限は `password` で `login` 送信
  4. 成功後：設定/在席を取得 → ポーリング同期開始
* **UI**

  * グループメニュー（ジャンプ）・管理モーダル（権限による表示制御）
  * CSV エクスポート／インポート（名簿 + 在席）
  * 拠点追加・削除・名称変更・PW 変更（権限／再認証に準拠）
* **在席操作**

  * ステータス・戻り時間・備考を行単位で即時反映（ローカル保存 + サーバ push）
  * 配色：在席/外出/休み/帰宅/在宅/出張/研修/健診/コアドック
  * モバイルはカード表示

### 2.7 バックアップ

* 保存先フォルダ：`1M2O6LSKEPFwJDz-L5mjwjZye_KyNAeO9`
* 保存物：`config.json` / `data.json` / `offices.json` / `combined.csv` / `meta.txt`
* タイミング：`setConfigFor`（インポート等）前、`deleteOffice` 前

### 2.8 導入・運用手順

1. **GAS デプロイ**

   * コード保存 → **新しいデプロイ**（ウェブアプリ）
2. **初回のみ（super 秘密セット）**

   * ファイル末尾の **RUN-ONCE** ブロックに初期 PW を記入
   * 関数 `RUN_ONCE_INIT_SUPER_SECRET()` を**1回実行**
   * プロパティ `presence:SUPER_SALT` / `presence:SUPER_KEY_B64` が作成されたら
     → **RUN-ONCE ブロックを削除**して保存・（必要なら）再デプロイ
3. **フロント側**

   * `REMOTE_ENDPOINT` を最新 Web アプリ URL に設定
4. **ログイン**

   * super：ノンス/HMAC 経由
   * officeAdmin / user：従来の拠点パスワード

### 2.9 互換性

* 1.41 のフロントでも **一般／拠点管理者ログインは可**。
* ただし **super 管理者は 1.42 フロント必須**（HMAC 実装が必要）。

# 今後の開発目標（統合版）

## P0（即対応・短期導入）

### 0-1. API通信の現代化：JSONP卒業（開発用から先行）

* **方針**：開発環境（whereabouts\_TEST）で **fetch + POST** に移行、GASは**JSON/JSONPの二刀流**で後方互換。
* **GAS（開発用のみ先行）**

  * `doGet` は現状維持＋`callback` 無しは **JSON** 返却。
  * **`doPost` 追加**：`action=...&token=...` を **`application/x-www-form-urlencoded`** で受付（プリフライト回避）。
  * **CORS**（JSON時のみ）：`Access-Control-Allow-Origin: <TESTのPagesオリジン>`、`Allow-Methods: GET, POST`、`Allow-Headers: Content-Type`。
* **フロント（TESTのみ）**

  * すべてのAPIを **POST** 呼出に統一（本文：`action=...&token=...`）。
  * **CSP更新**：`script-src 'self'`（JSONP不要へ）、`connect-src 'self' https://script.google.com`（必要なら `googleusercontent.com` も）。
* **本番影響**：なし（JSONP継続）。検証完了後に本番も移行。

### 0-2. 端末下書き（localStorage）由来の“旧備考”表示対策

* **初回同期での欠落IDクリア**（名簿ID集合 − 在席キー集合を端末側で比較し、欠落IDの下書きを空上書き）。
* **キー命名強化**：`presence-board-v4:<officeId>:<configUpdated>`（名簿更新・拠点切替で過去下書きを自動無効化）。
* （任意）**手動クリアUI**／**TTL（例30日）**。

### 0-3. サーバ側ログアウト & 監査ログ

* **/logout**：トークン即失効（自然失効待ちをやめる）。
* **操作監査ログ**：名簿インポート/削除/PW変更/全置換などを記録（誰が・いつ・どこを・件数）。

### 0-4. 入力サニタイズ & ログイン耐性

* **サニタイズ**：name/title/ext/note をサーバ側で最低限エスケープ（`<>&"'`）。
* **レート制限**：ログイン連続失敗に遅延/一時ブロック。

async function hmacSha256(keyBytes, messageStr){
  const key = await crypto.subtle.importKey('raw', keyBytes, {name:'HMAC', hash:'SHA-256'}, false, ['sign']);

}

function el(tag, attrs={}, children=[]){
  const e = document.createElement(tag);
  for(const [k,v] of Object.entries(attrs||{})){
    if(v==null) continue;
    if(k==='class') e.className = v;
    else if(k==='text') e.textContent = String(v);
    else if(k==='html'){ /* 使用禁止 */ e.textContent = String(v); }
    else e.setAttribute(k, String(v));
  }
  (children||[]).forEach(c=>{
    if(typeof c==='string'){ e.appendChild(document.createTextNode(c)); }
    else if(c) e.appendChild(c);
  });
  return e;
}

function makeLocalId(s){
  const seed = (s||"").normalize('NFKC').replace(/\s+/g,'');
  let h = 0; for(let i=0;i<seed.length;i++){ h = (h*31 + seed.charCodeAt(i)) >>> 0; }
  return "P" + (h.toString(16) + "00000000").slice(0,8);
}
function normalizeConfigClient(cfg){

  return groups.map(g=>({

      let id     = m?.id ? String(m.id) : "";

      return { name, ext, id };

  }));
}

/* ===== JSONP ===== */
function jsonp(url, timeout=20000){
  return new Promise((resolve)=>{
    const cb = 'cb_'+Math.random().toString(36).slice(2);
    let done=false;
    const cleanup=(s)=>{ try{ delete window[cb]; }catch(e){} if(s){ if(s.remove){s.remove();} else if(s.parentNode){s.parentNode.removeChild(s);} } };
    const timer=setTimeout(()=>{ if(!done){ done=true; cleanup(script); resolve(null); } }, timeout);
    window[cb]=(data)=>{ if(done) return; done=true; clearTimeout(timer); cleanup(script); resolve(data); };
    const script=document.createElement('script');
    script.src = url + (url.includes('?')?'&':'?') + 'callback=' + cb + '&_=' + Date.now();
    script.onerror=()=>{ if(!done){ done=true; clearTimeout(timer); cleanup(script); resolve(null); } };
    document.body.appendChild(script);
  });
}

async function adminSetForChunked(office, dataObjFull, superProof){
  const entries = Object.entries(dataObjFull || {});
  if(entries.length===0){
    const q = [`action=setFor`,`office=${encodeURIComponent(office)}`,`data=${encodeURIComponent(JSON.stringify({updated:Date.now(), data:{}, full:true}))}`,`token=${encodeURIComponent(SESSION_TOKEN)}`];

    return await jsonp(`${REMOTE_ENDPOINT}?${q.join('&')}`);
  }
  const chunkSize = 100;
  let first = true, ok=true;
  for(let i=0;i<entries.length;i+=chunkSize){
    const chunk = Object.fromEntries(entries.slice(i, i+chunkSize));
    const obj = {updated:Date.now(), data:chunk, full:first};
    const q = [`action=setFor`,`office=${encodeURIComponent(office)}`,`data=${encodeURIComponent(JSON.stringify(obj))}`,`token=${encodeURIComponent(SESSION_TOKEN)}`];

    const res = await jsonp(`${REMOTE_ENDPOINT}?${q.join('&')}`);
    if(!(res && res.ok)) ok=false;
    first = false;
  }
  return ok?{ok:true}:{error:'chunk_failed'};
}

/* ===== CSVユーティリティ（式注入対策） ===== */
function csvProtectFormula(s){
  if(s==null) return '';
  const v = String(s);
  // 先頭が = + - @ または TAB の場合、先頭にシングルクォートを付与
  if(/^[=\+\-@\t]/.test(v)) return "'" + v;
  return v;
}
function toCsvRow(arr){
  return arr.map(v=>{
    const s = csvProtectFormula(v);
    if(/[",\n]/.test(s)) return '"' + s.replace(/"/g,'""') + '"';
    return s;
  }).join(',');
}
function makeNormalizedCSV(cfg, data){
  const rows = [];
  rows.push(toCsvRow(['group_index','group_title','member_order','id','name','ext','status','time','note']));
  (cfg.groups||[]).forEach((g,gi)=>{
    (g.members||[]).forEach((m,mi)=>{
      const id = m.id || '';
      const rec = (data && data[id]) || {};
      rows.push(toCsvRow([
        gi+1,
        g.title||'',
        mi+1,
        id,
        m.name||'',
        m.ext||'',
        rec.status|| (STATUSES[0]?.value || '在席'),
        rec.time||'',
        rec.note||''
      ]));
    });
  });
  return rows.join('\n');
}

/* ===== 重要操作の再認証（HMAC+Nonce） ===== */
async function getNonce(){
  const r = await jsonp(`${REMOTE_ENDPOINT}?action=getNonce`);
  if(!r || !r.nonce || !r.salt){ throw new Error('nonce_failed'); }
  return { nonce:r.nonce, salt:r.salt };
}
async function superHmacFlow(promptTitle='スーパー管理者パスワードを入力してください'){
  try{
    const pw = window.prompt(promptTitle);
    if(!pw){ toast('キャンセルしました', false); return null; }
    const {nonce, salt} = await getNonce();
    const kBytes = await sha256Bytes(salt + pw);
    const sig = await hmacSha256(kBytes, nonce);
    const hmac = toBase64(sig);
    return { hmac, nonce };
  }catch(e){
    toast('追加認証に失敗', false);
    return null;
  }
}

    if(!r.gi || !r.mi || !r.name){ continue; }

    g.members.push({ _mi:r.mi, name:r.name, ext:r.ext||'', id: r.id||undefined });

    g.members.sort((a,b)=> (a._mi||0)-(b._mi||0));

function parseCSV(text){
  const out=[]; let i=0, s=text;
  let row=[]; let field=''; let inq=false;
  function pushField(){ row.push(field); field=''; }
  function pushRow(){ out.push(row); row=[]; }
  while(i<s.length){
    const c=s[i++];
    if(inq){
      if(c==='"' && s[i]==='"'){ field+='"'; i++; }
      else if(c==='"'){ inq=false; }
      else field+=c;
    }else{
      if(c===','){ pushField(); }
      else if(c==='"'){ inq=true; }
      else if(c==='\n'){ pushField(); pushRow(); }
      else if(c==='\r'){ /* skip */ }
      else field+=c;
    }
  }
  if(field!=='') pushField();
  if(row.length) pushRow();
  return out;
}

        const merged = Object.assign({}, prev.data || {});
        for (var k in incoming.data) merged[k] = incoming.data[k];
        out = { updated: Math.max(Number(prev.updated)||0, Number(incoming.updated)||0, now()), data: merged };
      }

      const outStr = JSON.stringify(out);
      prop.setProperty(DATA_KEY, outStr);
      cache.put(KEY_PREFIX+'data:'+office, outStr, CACHE_TTL_SEC);
      return outJSONP(cb,{ok:true});
    } finally { try{ lock.releaseLock(); }catch(e2){} }
  }

  if (action==='getConfig'){
    const office = tokenOffice;
    const CONFIG_KEY = configKeyForOffice_(office);
    const noCache = safeParam_(e,'nocache','')==='1';
    const cKey    = KEY_PREFIX + 'cfg:' + office;
    const hit     = noCache ? null : cache.get(cKey);
    if (hit){ try{ return outJSONP(cb, JSON.parse(hit)); }catch(err){} }
    const v = prop.getProperty(CONFIG_KEY);
    let parsed;
    try{ parsed = normalizeConfig(JSON.parse(v)); }
    catch(err){ parsed = defaultConfigEmpty_(); }
    parsed.updated = typeof parsed.updated==='number' ? parsed.updated : now();
    const out = JSON.stringify(parsed);
    prop.setProperty(CONFIG_KEY, out);
    if (!noCache) cache.put(cKey, out, CACHE_TTL_SEC);
    return outJSONP(cb, parsed);
  }

  // 旧互換（adminPw を用いる古い呼び出し）：自拠点のみ
  if (action==='setConfig'){
    const office = tokenOffice;
    const offs = getOffices_();
    const adminPw = safeParam_(e,'adminPw','');
    if (adminPw!==offs[office].adminPassword) return outJSONP(cb,{error:'forbidden'});
    const CONFIG_KEY = configKeyForOffice_(office);
    const DATA_KEY   = dataKeyForOffice_(office);
    const dataRaw = safeParam_(e,'data','');
    try{
      const json = normalizeConfig(JSON.parse(dataRaw));
      if (!json || !Array.isArray(json.groups)) throw new Error('bad');
      json.updated = now();
      const out = JSON.stringify(json);
      const lock = LockService.getScriptLock();
      try{
        lock.tryLock(500);
        prop.setProperty(CONFIG_KEY, out);
        if (RESET_DATA_ON_CONFIG_CHANGE){
          const empty = JSON.stringify({updated:0, data:{}});
          prop.setProperty(DATA_KEY, empty);
        }
        cache.put(KEY_PREFIX+'cfg:'+office, out, CACHE_TTL_SEC);
        cache.remove(KEY_PREFIX+'data:'+office);
      }finally{ try{ lock.releaseLock(); }catch(e2){} }
      return outJSONP(cb,{ok:true});
    }catch(err){ return outJSONP(cb,{error:'bad_config'}); }
  }

  if (action==='clearData'){
    const office = tokenOffice;
    const offs   = getOffices_();
    const adminPw = safeParam_(e,'adminPw','');
    if (adminPw!==offs[office].adminPassword) return outJSONP(cb,{error:'forbidden'});
    const DATA_KEY   = dataKeyForOffice_(office);
    const empty = JSON.stringify({updated:0, data:{}});
    prop.setProperty(DATA_KEY, empty);
    CacheService.getScriptCache().remove(KEY_PREFIX + 'data:' + office);
    return outJSONP(cb,{ok:true});
  }

  // ===== 管理API =====

  // 拠点一覧（認証後：super=全拠点、officeAdmin=自拠点）
  if (action==='listOffices'){
    const offs = getOffices_();
    if(roleIsSuper_(prop, token)){
      const offices = Object.keys(offs).map(id=>({id, name: offs[id].name}));
      return outJSONP(cb, {offices});
    }else{
      const id = tokenOffice;
      return outJSONP(cb, {offices:[{id, name: offs[id].name}]});
    }
  }

  // 指定拠点の get / set / getConfig / setConfig
  if (action==='getFor'){
    const office = safeParam_(e,'office','');
    const offs = getOffices_(); if(!offs[office]) return outJSONP(cb,{error:'no_office'});
    if(!canAdminOffice_(prop, token, office)) return outJSONP(cb,{error:'forbidden'});
    const DATA_KEY = dataKeyForOffice_(office);
    const noCache = safeParam_(e,'nocache','')==='1';
    const cKey    = KEY_PREFIX + 'data:' + office;
    const hit     = noCache ? null : cache.get(cKey);
    if (hit){ try{ return outJSONP(cb, JSON.parse(hit)); }catch(err){} }
    const v = prop.getProperty(DATA_KEY) || '{"updated":0,"data":{}}';
    try { if (!noCache) cache.put(cKey, v, CACHE_TTL_SEC); return outJSONP(cb, JSON.parse(v)); }
    catch(err){ return outJSONP(cb,{updated:0,data:{}}); }
  }

  if (action==='setFor'){
    const office = safeParam_(e,'office','');
    const offs = getOffices_(); if(!offs[office]) return outJSONP(cb,{error:'no_office'});
    if(!canAdminOffice_(prop, token, office)) return outJSONP(cb,{error:'forbidden'});
    const DATA_KEY = dataKeyForOffice_(office);
    const dataRaw = safeParam_(e,'data','{"updated":0,"data":{}}');
    if (dataRaw && dataRaw.length>MAX_SET_BYTES) return outJSONP(cb,{error:'too_large'});

    let incoming;
    try{
      incoming = JSON.parse(dataRaw);
      if (!incoming || typeof incoming!=='object' || typeof incoming.updated!=='number' || typeof incoming.data!=='object')
        return outJSONP(cb,{error:'bad_data'});
    }catch(err){ return outJSONP(cb,{error:'bad_json'}); }

    const lock = LockService.getScriptLock();
    try{
      lock.tryLock(500);

      const prevRaw = prop.getProperty(DATA_KEY) || '{"updated":0,"data":{}}';
      let prev; try{ prev = JSON.parse(prevRaw); }catch(_){ prev = {updated:0,data:{}}; }

      let out;
      if (incoming.full === true) {
        out = { updated: incoming.updated || now(), data: incoming.data || {} };
      } else {
        const merged = Object.assign({}, prev.data || {});
        for (var k in incoming.data) merged[k] = incoming.data[k];
        out = { updated: Math.max(Number(prev.updated)||0, Number(incoming.updated)||0, now()), data: merged };
      }

      const outStr = JSON.stringify(out);
      prop.setProperty(DATA_KEY, outStr);
      cache.put(KEY_PREFIX+'data:'+office, outStr, CACHE_TTL_SEC);
      return outJSONP(cb,{ok:true});
    } finally { try{ lock.releaseLock(); }catch(e2){} }
  }

  if (action==='getConfigFor'){
    const office = safeParam_(e,'office','');
    const offs = getOffices_(); if(!offs[office]) return outJSONP(cb,{error:'no_office'});
    if(!canAdminOffice_(prop, token, office)) return outJSONP(cb,{error:'forbidden'});
    const CONFIG_KEY = configKeyForOffice_(office);
    const noCache = safeParam_(e,'nocache','')==='1';
    const cKey    = KEY_PREFIX + 'cfg:' + office;
    const hit     = noCache ? null : cache.get(cKey);
    if (hit){ try{ return outJSONP(cb, JSON.parse(hit)); }catch(err){} }
    const v = prop.getProperty(CONFIG_KEY);
    let parsed;
    try{ parsed = normalizeConfig(JSON.parse(v)); }
    catch(err){ parsed = defaultConfigEmpty_(); }
    parsed.updated = typeof parsed.updated==='number' ? parsed.updated : now();
    const out = JSON.stringify(parsed);
    prop.setProperty(CONFIG_KEY, out);
    if (!noCache) cache.put(cKey, out, CACHE_TTL_SEC);
    return outJSONP(cb, parsed);
  }

  if (action==='setConfigFor'){
    const office = safeParam_(e,'office','');
    const offs = getOffices_(); if(!offs[office]) return outJSONP(cb,{error:'no_office'});
    if(!canAdminOffice_(prop, token, office)) return outJSONP(cb,{error:'forbidden'});

    // スーパー管理者であれば再認証必須
    if(roleIsSuper_(prop, token)){
      const chk = requireSuperAndPw_(prop, token, e);
      if(!chk.ok) return outJSONP(cb,{error:chk.error});
    }

    const CONFIG_KEY = configKeyForOffice_(office);
    const DATA_KEY   = dataKeyForOffice_(office);
    const dataRaw = safeParam_(e,'data','');

    // 処理前バックアップ（CSVインポートの安全弁）
    try{
      backupOfficeSnapshot_(office, 'import');
    }catch(err){
      return outJSONP(cb,{error:'backup_failed'});
    }

    try{
      const json = normalizeConfig(JSON.parse(dataRaw));
      if (!json || !Array.isArray(json.groups)) throw new Error('bad');
      json.updated = now();
      const out = JSON.stringify(json);
      const lock = LockService.getScriptLock();
      try{
        lock.tryLock(500);
        prop.setProperty(CONFIG_KEY, out);
        if (RESET_DATA_ON_CONFIG_CHANGE){
          const empty = JSON.stringify({updated:0, data:{}});
          prop.setProperty(DATA_KEY, empty);
        }
        cache.put(KEY_PREFIX+'cfg:'+office, out, CACHE_TTL_SEC);
        cache.remove(KEY_PREFIX+'data:'+office);
      }finally{ try{ lock.releaseLock(); }catch(e2){} }
      return outJSONP(cb,{ok:true});
    }catch(err){ return outJSONP(cb,{error:'bad_config'}); }
  }

  // 拠点名変更（自拠点はofficeAdmin可、全拠点はsuperAdmin可）
  if (action==='renameOffice'){
    const office = safeParam_(e,'office','');
    const newName = safeParam_(e,'name','');
    if(!newName) return outJSONP(cb,{error:'bad_name'});
    const offs = getOffices_();
    if(!offs[office]) return outJSONP(cb,{error:'no_office'});
    if(!canAdminOffice_(prop, token, office)) return outJSONP(cb,{error:'forbidden'});
    offs[office].name = newName;
    setOffices_(offs);
    return outJSONP(cb,{ok:true});
  }

  // 拠点追加（superAdminのみ、再認証不要）
  if (action==='addOffice'){
    if(!roleIsSuper_(prop, token)) return outJSONP(cb,{error:'forbidden'});
    const id   = safeParam_(e,'id','');
    const name = safeParam_(e,'name','');
    const pw   = safeParam_(e,'password','');
    const apw  = safeParam_(e,'adminPassword','');
    if(!/^[A-Za-z0-9_-]+$/.test(id)) return outJSONP(cb,{error:'bad_id'});
    if(!name || !pw || !apw) return outJSONP(cb,{error:'bad_input'});
    const offs = getOffices_();
    if(offs[id]) return outJSONP(cb,{error:'exists'});
    offs[id] = { name, password: pw, adminPassword: apw };
    setOffices_(offs);
    // 初期設定は空名簿
    const prop2 = PropertiesService.getScriptProperties();
    const cfg = defaultConfigEmpty_();
    prop2.setProperty(configKeyForOffice_(id), JSON.stringify(cfg));
    prop2.setProperty(dataKeyForOffice_(id), JSON.stringify({updated:0, data:{}}));
    return outJSONP(cb,{ok:true});
  }

  // 拠点削除（superAdminのみ・再認証必須・処理前バックアップ）
  if (action==='deleteOffice'){
    if(!roleIsSuper_(prop, token)) return outJSONP(cb,{error:'forbidden'});
    const chk = requireSuperAndPw_(prop, token, e);
    if(!chk.ok) return outJSONP(cb,{error:chk.error});

    const id = safeParam_(e,'id','');
    const offs = getOffices_();
    if(!offs[id]) return outJSONP(cb,{error:'no_office'});

    // バックアップ（失敗したら中止）
    let backupInfo;
    try{
      backupOfficeSnapshot_(id, 'delete');
    }catch(err){
      return outJSONP(cb,{error:'backup_failed'});
    }

    delete offs[id];
    setOffices_(offs);
    const prop2 = PropertiesService.getScriptProperties();
    prop2.deleteProperty(configKeyForOffice_(id));
    prop2.deleteProperty(dataKeyForOffice_(id));
    const cache2 = CacheService.getScriptCache();
    cache2.remove(KEY_PREFIX+'cfg:'+id);
    cache2.remove(KEY_PREFIX+'data:'+id);
    return outJSONP(cb,{ok:true});
  }

  // パスワード変更（superAdminは全拠点で再認証必須／officeAdminは自拠点のみ）
  if (action==='setOfficePassword'){
    const id  = safeParam_(e,'id','');
    const pw  = safeParam_(e,'password','');
    const apw = safeParam_(e,'adminPassword','');
    const offs = getOffices_();
    if(!offs[id]) return outJSONP(cb,{error:'no_office'});

    if(roleIsSuper_(prop, token)){
      const chk = requireSuperAndPw_(prop, token, e);
      if(!chk.ok) return outJSONP(cb,{error:chk.error});
    }else if(roleIsOfficeAdmin_(prop, token)){
      if(getOfficeByToken_(prop, token) !== id) return outJSONP(cb,{error:'forbidden'});
    }else{
      return outJSONP(cb,{error:'forbidden'});
    }

    if(pw)  offs[id].password      = pw;
    if(apw) offs[id].adminPassword = apw;
    setOffices_(offs);
    return outJSONP(cb,{ok:true});
  }

  return outJSONP(cb,{error:'unknown_action'});
}
