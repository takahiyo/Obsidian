# 在席確認表：v1.42 → 現行版 まとめ

## 更新内容（Change Log）

### 基盤・通信

* JSONP を廃止し、`fetch(POST)`（`application/x-www-form-urlencoded`）へ全面移行。
* Cloudflare Workers を中継プロキシとして導入

  * フロント → **Worker** → GAS(ウェブアプリ) の経路に統一。
  * CORS/Origin 制御、メソッド固定、ヘッダ最小化でセキュア化。
* CSP を厳格化

  * `connect-src` を Worker のみ許可、`object-src 'none'`、インライン最小化など。

### 認証・権限

* 3ロール運用（`user` / `officeAdmin` / `superAdmin`）。
* **スーパー管理者**：HMAC（`salt + password` をキー、`nonce` をメッセージ）で追加認証。

  * `getNonce` → HMAC 生成 → `login(hmac, nonce)` → `role: superAdmin`。
* トークンの TTL/自動更新（`renew`）を実装。期限前 80% で再発行。

### データモデル・API

* 設定（名簿）`getConfig`：`{version, updated, groups, menus}`。

  * `groups[].members[]` は `{name, ext, id}`／`id`が不正時はクライアントで補正（ハッシュ生成）。
* 在席データ `get` / `set`：差分更新（1人単位）を標準化。
* 管理 API：

  * `listOffices`, `getFor`, `getConfigFor`, `setFor`（100件チャンク）,
    `setConfigFor`, `renameOffice`, `setOfficePassword`, `getNonce`。
* CSV I/O を強化

  * エクスポート/インポートの正規ヘッダ固定、数百件対応（サーバ側バックアップ前提）。

### フロント（UI/UX）

* **レイアウトを v1.42 値で再構築**：列幅変数（name/ext/status/time/note）を復元。
* グリッド：最大3列、**1列になったら必ずカード化**（幅が広くても `data-cols=1` で強制）。
* ステータスの色/属性を JSON（`menus.statuses`）で拠点ごとに管理

  * `requiresTime`, `clearOn`, `color` を動的反映（CSS を動的生成）。
* `requiresTime` による戻り時間セレクトの有効/無効切替、`clearOn` で値クリア。
* ローカル保存キーを **v4**（`officeId` + `configUpdated`）に更新。

  * 旧 `v3` を初回ログイン時に移行。
* グループジャンプメニュー／管理パネルの操作性改善。

### 運用・キャッシュ

* GitHub Pages のキャッシュ影響回避策として `?v=xxx` のクエリ版を推奨。
* Worker 側は `POST` 経由のみ、ブラウザキャッシュは `no-store` で抑止。

## 仕様書（Current Spec）

### アーキテクチャ

* **Frontend（静的）**：GitHub Pages（または任意ホスティング）
* **Proxy**：Cloudflare Workers（`REMOTE_ENDPOINT`）
* **Backend**：GAS（ウェブアプリ `exec`）

```
Browser (POST) → Cloudflare Worker → GAS WebApp (doPost)
```

### セキュリティ

* CSP：`default-src 'self'` / `connect-src` を Worker のみ許可。
* 通信：`POST` 固定、`application/x-www-form-urlencoded`。
* 認証：JWT/類似トークン（GAS発行）＋ 期限前更新（`renew`）。
* 権限：

  * `user`：自拠点の一覧・更新（自席情報）
  * `officeAdmin`：自拠点の設定/CSV I/O
  * `superAdmin`：**HMAC 追加認証**で全拠点操作
* 重要操作（CSVインポート・拠点削除・PW変更など）：`getNonce`→HMAC で再認証。

### GAS 側 API（抜粋）

* `publicListOffices`：拠点一覧（公開）
* `getNonce`：`{nonce, salt}`
* `login`：

  * 通常：`{office, password}` → `role: user/officeAdmin`
  * Super：`{office, hmac, nonce}` → `role: superAdmin`
* `renew`: トークン延長
* `getConfig` / `setConfigFor`（super/officeAdmin）
* `get` / `set`（差分）
* `listOffices`, `getFor`, `getConfigFor`, `setFor`, `renameOffice`, `setOfficePassword`

### データスキーマ

* **Config**

  ```ts
  {
    version: 2,
    updated: number, // epoch ms
    groups: [
      { title: string, members: [{ id: string, name: string, ext?: string }] }
    ],
    menus?: {
      statuses: [
        { value: string, color: "\#RRGGBB", requiresTime: boolean, clearOn: boolean }
      ],
      noteOptions: string[],
      timeStepMinutes: number // 5..60
    }
  }
  ```
* **Presence Data**

  ```ts
  {
    updated: number, // epoch ms
    data: {
      [memberId: string]: { ext: string, status: string, time: string, note: string }
    },
    full?: boolean // setFor 初回チャンクで true
  }
  ```

### フロントの挙動

* 起動時：`publicListOffices` → ログイン

  * super なら HMAC → 失敗時は通常PWへフォールバック
* ログイン成功：`getConfig(nocache=1)` → `render()` → `get(nocache=1)` 適用
* 同期：

  * データポーリング：2s + ジッター
  * 設定監視：120s（`updated` 比較で再描画）
  * `renew`：期限の 80% で自動実行
* UI：

  * `PANEL_MIN_PX=760`、`MAX_COLS=3`、`board[data-cols="1"]` でカード化
  * `statuses` 配色は動的 CSS（値 → クラス）
  * 編集保護：フォーカス/IME中は差し替えを抑止
  * CSV I/O：フロントでパース → サーバにチャンク適用

### レイアウト（v1.42 値）

* 列幅変数（`--base-*`、`--scale-*`、`--min-*`）を復元。
* **1列＝常時カード化**（ラベル表示、氏名を見出し化）。
* `requiresTime` に応じて「戻り時間」を動的に disabled。

### エラーハンドリング

* 通信失敗・認証失効時は `logout()` → ログイン画面へ。
* トーストでユーザー通知（成功/失敗色分け）。

### 運用手順（要点）

1. **GAS**：`doPost` 実装／デプロイ → 新しい `exec` URL を取得
2. **Worker**：`GAS_ENDPOINT` をその `exec` に設定 → デプロイ
3. **Frontend**：`REMOTE_ENDPOINT` を Worker に設定 → デプロイ（GitHub Pages 等）
4. キャッシュ回避：リリース時は `?v=日時` で読み替え推奨

## 今後の開発目標（Roadmap）

### 1) 可用性・運用

* **バックアップ/リストア API**（CSVとは別に JSON 丸ごと）
* レート制限・簡易 WAF（Worker で IP/UA 基準のクールダウン）
* 監査ログ（だれが、いつ、何を変更したか／CSV含む）

### 2) 使い勝手

* オフライン一時保存 + 再接続時の自動反映（競合時はサーバ勝ち）
* 高速検索／フィルタ（氏名・ステータス・備考）
* ステータスのプリセット切替（拠点テンプレート）

### 3) UI/アクセシビリティ

* キーボード操作の最適化（上下左右移動、Enter で次セル・IME考慮）
* 色弱対応パレット／ハイコントラストモード
* 印刷レイアウト（ページブレイク・縮小率調整）

### 4) セキュリティ強化

* スーパー管理者の **TOTP**（ワンタイムコード）併用
* トークン署名方式の抽象化（将来の発行基盤変更に備える）

### 5) パフォーマンス

* 大規模拠点（数千人）に向けた **仮想スクロール**／差分パッチ配信
* `get/set` のサーバ内 TTL キャッシュ＋If-None-Match で帯域削減

### 6) 周辺連携

* Slack / Teams 通知（特定ステータスへ遷移時）
* 予定表連携（出張・休みを自動下書き）

### メモ（既知の注意点）

* Pages のキャッシュが強い環境では **クエリパラメータ**付き URL を常用。
* フロントの `menus` が空配列でも動くよう **デフォルトメニュー**を常備。
* `id` が不正（空／全角含む）の場合はクライアントで補正し、以降固定。

必要なら、このまとめをそのまま **運用ドキュメント**（PDF/MD）に整形します。

function qsEncode(obj){
  const p = new URLSearchParams();
  Object.entries(obj||{}).forEach(([k,v])=>{
    if(v===undefined || v===null) return;
    p.append(k, String(v));
  });
  return p.toString();
}

      cache: 'no-store'
    });
    if(!res.ok) return null;

  }catch(e){
    return null;
  }finally{
    clearTimeout(t);
  }
}

async function hmacSha256(keyBytes, messageStr){

const noteTimers = new Map();
function debounceRowPush(key, delay=900){
  if(noteTimers.has(key)) clearTimeout(noteTimers.get(key));
  noteTimers.set(key, setTimeout(()=>{ noteTimers.delete(key); pushRowDelta(key); }, delay));
}
function markEditing(el){ if(!el) return; el.dataset.editing = '1'; }

function wireEvents(){
  board.querySelectorAll("input, select").forEach(el=>{
    el.addEventListener('focus', ()=> markEditing(el));
    el.addEventListener('blur',  ()=> unmarkEditing(el));
  });

  board.querySelectorAll("select[name='status']").forEach(sel=>{
    sel.addEventListener("change", ()=>{
      const key  = sel.id.replace("status-","");
      const time = document.getElementById(`time-${key}`);
      const note = document.getElementById(`note-${key}`);
      if(clearOnSet.has(sel.value)){ if(time) time.value=""; if(note) note.value=""; }
      if(time) toggleTimeEnable(sel, time);
      saveLocal(); pushRowDelta(key); recolor();
    });
  });
  board.querySelectorAll("select[name='time']").forEach(sel=>{
    sel.addEventListener("change", ()=>{ const key = sel.id.replace("time-",""); saveLocal(); pushRowDelta(key); });
  });
  board.querySelectorAll("input[name='ext']").forEach(inp=>{
    inp.addEventListener('change', ()=>{ const key = inp.id.replace("ext-",""); saveLocal(); pushRowDelta(key); });
  });
  board.querySelectorAll("input[name='note']").forEach(inp=>{
    const key = inp.id.replace("note-","");
    inp.addEventListener('compositionstart', ()=>{ inp.dataset.composing = '1'; });
    inp.addEventListener('compositionend',  ()=>{ inp.dataset.composing = ''; saveLocal(); pushRowDelta(key); });
    inp.addEventListener('input', ()=>{ saveLocal(); if(!inp.dataset.composing) debounceRowPush(key, 900); });
    inp.addEventListener('change', ()=>{ saveLocal(); pushRowDelta(key); });
  });
}

async function adminSetForChunked(office, dataObjFull, superProof){
  const entries = Object.entries(dataObjFull || {});
  if(entries.length===0){
    const base = { action:'setFor', office, token: SESSION_TOKEN, data: JSON.stringify({updated:Date.now(), data:{}, full:true}) };
    if(superProof){ base.superHmac = superProof.hmac; base.nonce = superProof.nonce; }
    return await apiPost(base);
  }
  const chunkSize = 100;
  let first = true, ok=true;
  for(let i=0;i<entries.length;i+=chunkSize){
    const chunk = Object.fromEntries(entries.slice(i, i+chunkSize));
    const obj = {updated:Date.now(), data:chunk, full:first};
    const q = { action:'setFor', office, token: SESSION_TOKEN, data: JSON.stringify(obj) };

        gi+1,

        m.ext||'',

function parseCSV(text){
  const out=[]; let i=0, s=text;
  let row=[]; let field=''; let inq=false;
  function pushField(){ row.push(field); field=''; }
  function pushRow(){ out.push(row); row=[]; }
  while(i<s.length){
    const c=s[i++];
    if(inq){
      if(c==='"' && s[i]==='"'){ field+='"'; i++; }
      else if(c==='"'){ inq=false; }
      else field+=c;
    }else{
      if(c===','){ pushField(); }
      else if(c==='"'){ inq=true; }
      else if(c==='\n'){ pushField(); pushRow(); }
      else if(c==='\r'){ /* skip */ }
      else field+=c;
    }
  }
  if(field!=='') pushField();
  if(row.length) pushRow();
  return out;
}

function hmacVerifyWithStoredKey_(nonce, hmacIn){
  const secret = getSuperSecret_(); if(!secret) return false;
  const clientB64 = String(hmacIn||'').replace(/ /g, '+');  // 念のため救済
  if(!clientB64) return false;

  const valueBytes = Utilities.newBlob(String(nonce)).getBytes();
  const keyBytes   = Utilities.base64Decode(secret.keyB64);
  const sigBytes   = Utilities.computeHmacSha256Signature(valueBytes, keyBytes);
  const serverB64  = Utilities.base64Encode(sigBytes);

  if(serverB64.length !== clientB64.length) return false;
  let ok = 0; for(let i=0;i<serverB64.length;i++){ ok |= (serverB64.charCodeAt(i) ^ clientB64.charCodeAt(i)); }
  return ok === 0;
}

    if(!consumeNonce_(cache, nonce)) return json_({error:'super_hmac_invalid'});
    if(!hmacVerifyWithStoredKey_(nonce, hmac)) return json_({error:'super_hmac_invalid'});

    const id = p_(e,'id','');
    const offs = getOffices_(); if(!offs[id]) return json_({error:'no_office'});

    try{ backupOfficeSnapshot_(id, 'delete'); }
    catch(_){ return json_({error:'backup_failed'}); }

    delete offs[id];
    setOffices_(offs);

    const prop2 = PropertiesService.getScriptProperties();
    prop2.deleteProperty(configKeyForOffice_(id));
    prop2.deleteProperty(dataKeyForOffice_(id));
    const cache2 = CacheService.getScriptCache();
    cache2.remove(KEY_PREFIX+'cfg:'+id);
    cache2.remove(KEY_PREFIX+'data:'+id);
    return json_({ok:true});
  }

  if(action === 'setOfficePassword'){
    const id  = p_(e,'id','');
    const pw  = p_(e,'password','');
    const apw = p_(e,'adminPassword','');
    const offs = getOffices_(); if(!offs[id]) return json_({error:'no_office'});

    if(roleIsSuper_(prop, token)){
      const chk = requireSuperHmac_(e);
      if(!chk.ok) return json_({error:chk.error});
    }else if(roleIsOfficeAdmin_(prop, token)){
      if(getOfficeByToken_(prop, token) !== id) return json_({error:'forbidden'});
    }else{
      return json_({error:'forbidden'});
    }

    if(pw)  offs[id].password = pw;
    if(apw) offs[id].adminPassword = apw;
    setOffices_(offs);
    return json_({ok:true});
  }

  // ===== スーパー管理者パスワード変更 =====
  // 要求: superHmac + nonce + newPassword（現行鍵によるHMAC検証に成功したらローリング）
  if(action === 'setSuperPassword'){
    const superHmac   = p_(e,'superHmac','').trim();
    const nonce       = p_(e,'nonce','').trim();
    const newPassword = p_(e,'newPassword','').trim();
    if(!superHmac || !nonce || !newPassword) return json_({error:'bad_request'});

    // 使い捨てノンス確認
    if(!consumeNonce_(cache, nonce)) return json_({error:'super_hmac_invalid'});
    if(!hmacVerifyWithStoredKey_(nonce, superHmac)) return json_({error:'unauthorized'});

    // 新saltはBase64に統一（互換）
    const props   = PropertiesService.getScriptProperties();
    const saltBin = Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, Utilities.newBlob(Utilities.getUuid()).getBytes());
    const newSalt = Utilities.base64Encode(saltBin);

    const keyBytes = Utilities.computeDigest(
      Utilities.DigestAlgorithm.SHA_256,
      Utilities.newBlob(newSalt + newPassword).getBytes()
    );
    const newKeyB64 = Utilities.base64Encode(keyBytes);

    // 旧値の薄いバックアップ（任意）
    const oldSalt = props.getProperty(PROP_SUPER_SALT) || '';
    const oldKey  = props.getProperty(PROP_SUPER_KEY_B64) || '';
    const stamp   = Utilities.formatDate(new Date(), Session.getScriptTimeZone()||'Asia/Tokyo','yyyyMMdd_HHmmss');

    props.setProperty(PROP_SUPER_SALT,    newSalt);
    props.setProperty(PROP_SUPER_KEY_B64, newKeyB64);
    props.setProperty('presence:SUPER_SALT_BAK_'+stamp, oldSalt);
    props.setProperty('presence:SUPER_KEY_B64_BAK_'+stamp, oldKey);
    props.setProperty('presence:SUPER_LAST_ROTATED_AT', ''+now_());

    return json_({ok:true});
  }

  return json_({error:'unknown_action'});
}

// 🟠 ここに貼る: Cloudflare Workers（presence-proxy の index.js など。Worker本体）
//    既存を置換してデプロイしてください。GASがHTMLを返してもJSONで包んで返す安全版。

export default {
  async fetch(request) {
    const ALLOW = [
      'https://takahiyo.github.io',
      'https://takahiyo.github.io/whereabouts_TEST'
    ];
    const origin = request.headers.get('Origin') || '';
    const cors = {
      'Access-Control-Allow-Origin': ALLOW.includes(origin) ? origin : 'https://takahiyo.github.io',
      'Vary': 'Origin',
      'Access-Control-Allow-Methods': 'POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type',
      'Access-Control-Max-Age': '600'
    };

    if (request.method === 'OPTIONS') {
      return new Response(null, { status: 204, headers: cors });
    }
    if (request.method !== 'POST') {
      return new Response(JSON.stringify({ error: 'method_not_allowed' }), {
        status: 405, headers: { ...cors, 'Content-Type': 'application/json' }
      });
    }

    // ★ あなたの GAS /exec URL（最新デプロイの /exec）
    const GAS_URL = 'https://script.google.com/macros/s/AKfycbw6WHnnrQaQGJsWXSgrs6D2m9Uc2g6Pyf_NY1b_WCx80k2U-OXqPoshhzCYe7y4WtAJ/exec';

    // 受信ボディをパラメータ化
    let params = new URLSearchParams();
    try {
      const ct = (request.headers.get('Content-Type') || '').toLowerCase();
      if (ct.includes('application/json')) {
        const obj = await request.json().catch(() => ({}));
        Object.entries(obj || {}).forEach(([k, v]) => params.append(k, String(v)));
      } else if (ct.includes('application/x-www-form-urlencoded')) {
        const fd = await request.formData();
        for (const [k, v] of fd.entries()) params.append(k, String(v));
      } else {
        // 想定外はテキスト→URLSearchParamsとして試行
        const txt = await request.text();
        new URLSearchParams(txt).forEach((v, k) => params.append(k, v));
      }
    } catch (err) {
      return new Response(JSON.stringify({ error: 'bad_request', message: String(err) }), {
        status: 400, headers: { ...cors, 'Content-Type': 'application/json' }
      });
    }

    // GASにPOST
    let upstream;
    try {
      upstream = await fetch(GAS_URL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
        body: params
      });
    } catch (err) {
      return new Response(JSON.stringify({ error: 'upstream_fetch_failed', message: String(err) }), {
        status: 502, headers: { ...cors, 'Content-Type': 'application/json' }
      });
    }

    // 常に JSON で返す（GASがHTMLでも包む）
    const text = await upstream.text();
    const type = (upstream.headers.get('content-type') || '').toLowerCase();
    if (type.includes('application/json')) {
      return new Response(text, {
        status: upstream.status,
        headers: { ...cors, 'Content-Type': 'application/json' }
      });
    }
    // JSONでない→短いダンプをJSONに包む
    return new Response(JSON.stringify({
      error: 'upstream_not_json',
      status: upstream.status,
      preview: text.slice(0, 400)  // 先頭だけ返す（デバッグ用）
    }), {
      status: 502, headers: { ...cors, 'Content-Type': 'application/json' }
    });
  }
}
