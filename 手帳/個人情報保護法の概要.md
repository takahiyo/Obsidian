# 施行

20170530から全面施行

# 改正の大筋

- それまでは取り扱う個人情報が5000以下だと適用対象外だったが、撤廃された
    
	法人に限定されず、営利・非営利も問われないため、個人事業主からNPOまで全て対象
    

# 概要

- 違反がみられると個人情報保護委員会（内閣府）から指導・勧告等がある
    
	不正な利用（取得情報の売買等）でない限り、一発アウトではない
    
- 改善がされないと刑事罰が科される
    
	個人には30万円以下の罰金　若しくは　6か月以下の懲役　のどちらか、または両方
    
	法人のに対しても罰金刑が科される
    
- 不正な利用が認められた場合は一発アウト
    
	個人には50万円以下の罰金　若しくは　1年以下の懲役　のどちらか、または両方
    
	法人のに対しても罰金刑が科される
    

# 損害賠償の相場

- 氏名・住所・電話番号等の基本的な情報の場合、5,000円～15,000円／人
- エステのコース名やスリーサイズ等、秘匿性が高い情報際に35,000円／人の前例有り
- サプライチェーン攻撃により他企業に損害が発生し、情報漏洩の対応・調査費用、損害賠償で1億　※通信販売関連でクレジットカード情報も流出している
- フランスのホテル予約サイト運営が漏洩事故、サイト利用側だった日本のプリンスホテル等も管理責任を問われGDPR違反の疑いで調査中
    
	※20190826時点で制裁には至っていない
    

# GDPR

- General Data Protection Regulation：一般データ保護規則
- 20180525施行
- 個人データの域外への持ち出しを規制している
    
	氏名、年齢、住所は勿論、メールアドレス、位置情報、IPアドレス、Webサイトの閲覧履歴といった単体では個人を特定できない情報も含まれている
    
- 制裁金は、年間世界売り上げの4%か2,000万€（約26億円）のいずれか高い方が上限
- 取引先等の瑕疵で情報漏洩があったなら、その管理責任を問われる
- 直ちに制裁金が課されるものではなく、データ保護の徹底が為されていたかをみられる
    
	・管理者が情報漏えいリスクを認識して処理者にセキュリティ対策を指示していたか
    
	・その指示は適切だったか
    
	・指示の遵守を確認していたか
    

# セキュリティ事故の実態

- 重大な被害を被った企業は36%（2018年は42%）
- 平均被害総額は2.4億円、5%は10億円超
- 内容は「個人情報流出」「顧客情報」「業務提携先情報」「技術情報」「事業戦略情報」が上位
