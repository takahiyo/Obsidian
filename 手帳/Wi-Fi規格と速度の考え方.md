# 概要

#### Wi-Fi規格

- [[IEEE802.11]] — 2M / 2.4GHz
- [[11a]] — 54M / 5GHz / OFDM
- [[11b]] — 11M / 5GHz / DSSS
- [[11g]] — 54M / 2.4GHz / OFDM
- [[11n]] — Wi-Fi4 / 660M / 2.4GHz, 5GHz / MIMO, ビームフォーミング
- [[11ac]] — Wi-Fi5 / 6.9G / 5GHz / MU-MIMO, ビームフォーミング
- [[11ax]] — Wi-Fi6 / 9.6G / 2.4GHz, 5GHz / MU-MIMO, OFDMA, ビームフォーミング
- [[11be]] — Wi-Fi7 / 46G / 2.4GHz, 5GHz, 6GHz / 320MHz帯域幅, MU-MIMO, ビームフォーミング
