# 仕様書

```visual-basic
在席確認表 ドキュメント（v1.434 確定 / v1.435 仕様予定）
1. 概要

社内の在席状況（ステータス／戻り時間／備考／内線）をブラウザで編集・共有する単一HTMLアプリ。

サーバとは POST（JSON）で疎結合ポーリング連携。

CSVエクスポート/インポートにより一括更新・名簿差し替えが可能。

2. 用語

グループ：部署・チーム等のまとまり。盤面はグループ単位で複数パネル表示。

メンバー：氏名/内線/ID（サーバ採番）を持つ行。

ステータス：在席、外出、会議、テレワーク、休み（既定）。

戻り時間：時刻候補から選択（空欄可）。

備考：自由記入欄（v1.435で定型プルダウンを追加予定）。

MENUS（メニュー設定）：ステータスや備考候補、時間ステップ等を定義するJSON。

3. 更新履歴（主要）

v1.434（現行）

CSV入出力を正式対応

出力：日本語ヘッダで出力（Excel対策のBOM付与・式注入防止）。
列順：グループ番号, グループ名, 表示順, id, 氏名, 内線, ステータス, 戻り時間, 備考

入力：英語/日本語ヘッダのいずれかを受け入れ（列順固定）。
英語ヘッダ：group_index, group_title, member_order, id, name, ext, status, time, note

インポート後、名簿（config）再取得→IDマッピング→在席データを分割更新（チャンク）。

モバイル表示のアクセシビリティ改善（カード化/ラベル/行自己修復）。

ログオフ動作の堅牢化（UI/タイマー/セッションメタのクリア順序見直し）。

v1.433 以前

ステータスの requireTime／clearOnSet に基づく時刻の活性/初期化ロジック。

IME合成中の送信抑止、ローカル保存、最小限の自己修復など。

4. 仕様書（現行 v1.434）
4.1 画面構成

ヘッダ：タイトル（グループジャンプ）、管理、ログオフ。

グループメニュー：全体/各グループへスクロール。人数表示。

盤面：グループごとにテーブル（氏名／内線／ステータス／戻り時間／備考）。

管理モーダル：CSV入出力、拠点管理、MENUS編集。

ログイン：拠点選択＋パスワード（通常／スーパー管理者HMAC）。

トースト：操作結果／エラー表示。

診断バナー：自己修復発動時の記録（開発向け）。

4.2 レイアウト

1～3列可変グリッド。スマホ幅ではカード化（見出しラベル付与）。

4.3 認証・権限

ロール：user / officeAdmin / superAdmin。

セッション：sessionStorage にトークン/ロール/拠点情報を保存、期限前に renew。

4.4 同期

取得：2秒間隔のポーリング get。

反映：applyState は編集中/IME中の要素を尊重（上書きしない）。

送信：input/change を行単位で 900ms デバウンスし set 送信。

競合：基本は 後勝ち（Last Write Wins）。他端末の変更はポーリング反映されるが、編集中の項目は保護されるため視覚反映に遅延が出ることがある。

4.5 ステータスと時間

requireTime が付いたステータスは戻り時間を 活性化、付かないものは 無効化。

clearOnSet が付いたステータスを選ぶと、備考/戻り時間を クリア。

4.6 CSV 入出力の詳細

出力（v1.434 仕様）

ヘッダは日本語固定（BOM付加、式注入対策 ' 付与）。

表示順 は 1..n で連番（グループ内）。
※出力時に並び直されるため、インポート時に付けた任意の番号は、次の出力では連番に正規化される。

入力（受理条件）

ヘッダは 日本語または英語いずれかに完全一致（列順固定）。

行は空白のみのレコードを除外。

取り込みに必要な最小項目：グループ番号/表示順/氏名（いずれか欠落で その行は無視。既存データは残る）。

グループ名の扱い（現行実装の注意点）

同一グループ内で行ごとに グループ名 を参照し、最後に読んだ値が採用されます（空白も上書き対象）。
→ 実務上は 同一グループの全行で同じ名称を入れる運用を推奨。
（※将来版で “非空のみ採用” へ改善予定。）

IDの扱い

id が空欄でも サーバ側で新規採番されます（名簿＝config 更新後の再取得で新IDが付与される）。

在席データ 反映は、id が存在する行か、(グループ番号, グループ名, 表示順, 氏名, 内線) の一致から新IDを突き合わせて更新。突合できない新規は 名簿には載るが在席データは既定値（後からUIで編集可）。

ステータス/時間/備考の空欄インポート

空欄で取り込むと 空欄として上書きされる（＝出力時の内容を消したい場合は空でOK）。

順序ルール

表示順は member_order の昇順。CSVの行順は使いません。

4.7 管理

CSVエクスポート/インポート、拠点追加・削除・改名、パスワード更新、MENUS編集（JSON）。

superAdmin 操作は Nonce+HMAC の再認証必須。

4.8 アクセシビリティ

モバイル時は疑似ラベル表示、PC時は実ラベル非表示でaria冗長回避。

スクロール先ジャンプ、ヘッダ固定など。

4.9 セキュリティ

CSP 厳格化（default-src 'self' / Worker への connect を限定）。

すべて POST、application/json 応答を期待。

キャッシュ抑止メタ。

4.10 既知の制限

ポーリング（2秒）により即時性はSSE/WebSocketに劣る。

行の同時編集は後勝ち。細粒度のフィールドロックなし（編集中はローカル優先のため表示差が一時的にずれる）。

5. 受け入れ条件（v1.434）

日本語ヘッダでのCSVエクスポートが行え、Excelで文字化け/式化けしない（BOM＋式保護）。

日本語/英語ヘッダいずれのCSVでもインポート成功（列順固定）。

member_order 昇順で表示される（CSV行順に依存しない）。

id 空欄の新規行が名簿に追加され、再取得後にIDが付与される。

status/time/note の空欄取り込みが既存値を空欄に上書きする。

ログオフ後にログイン画面が確実に戻る（ネットワーク失敗時もUIが復帰）。

6. 次版 v1.435（UI強化） 仕様
6.1 要件（最優先）

備考：手入力に加え、プルダウンで定型選択が可能

選択肢：（空白） / 直出 / 直帰 / 直出・直帰

（空白） は 空文字（null等ではなく送受信上は ""） として扱う。

UI案：備考セルに select（定型） + input（自由欄） を並置。

保存値は 自由欄優先（自由欄が空なら定型値、両方空なら空）。

CSV上は従来の 備考1列のまま（互換）。

MENUS 既定：noteOptions を上記4候補に差し替え（※既存拠点は保存時に上書き可）。

戻り時間の候補を 07:00–22:00 に制限（空欄は常時選択可）

MENUS 拡張：timeStartHour: 7, timeEndHour: 22, timeStepMinutes: 30

UIは該当範囲のみに列挙（既存値が範囲外で保存されている場合は 表示のみ空欄として扱い、編集時に範囲内から再選択）。

ステータスが 在席 / テレワーク / 休み の場合、戻り時間・備考を自動クリア

MENUS の statuses に clearOnSet: true を付与（3種）。

UI動作：該当ステータス選択時、行内の戻り時間・備考（定型+自由）を空にし、時間セレクトは requireTime に応じて無効化。

内線は表示専用

盤面は テキスト表示のみに変更（入力不可）。

CSVでは 内線 列を引き続き入出力（UIからは変更できない）。

氏名ジャンプ（低優先）

方式A：グループメニューの兄弟として 氏名メニュー（全文字順／グループ内絞り込み）。

方式B：ヘッダに 検索ボックス（oninput即時フィルタ。ボタンなし）。一致行をハイライト＆スクロール可。

最初は方式Bを実装し、Aは様子見。

6.2 受け入れ条件（v1.435）

備考セルで定型選択/自由記入が併用でき、保存結果が期待どおり（自由欄優先）。

戻り時間の候補が 07:00–22:00 のみになる。

在席/テレワーク/休み に変更時、当該行の戻り時間・備考が空になる。

内線は編集できず、表示のみ。CSV経由の変更は反映可。

氏名検索で入力と同時に該当行がフィルタ/ハイライトされる（方式B）。

6.3 データ互換

CSVスキーマ変更なし。既存CSVはそのまま利用可。

MENUSは拡張（timeStartHour/timeEndHour、statusesのclearOnSet）だが、旧設定でも既定値で動作。

6.4 リリース/ロールバック

フロント単体変更。挙動不具合時は noteOptions を旧値に戻し、timeStart/End を未設定で24h列挙に戻せる。

7. 開発計画（短期タスク）

8. 中期ロードマップ（v1.436+）

即時同期：SSE/WebSocket 化（ポーリング置換）。

更新ログ：誰がいつ何を変更したかの簡易監査。

権限強化：グループ管理者ロール、表示専用ロール。

UI：氏名メニュー（方式A）、キーボードショートカット、アクセシビリティ微調整。

運用：バックアップ/復元の管理UI、CSV差分インポート（追記/上書きモード切替）。

9. テスト観点まとめ

CSV：日本語/英語ヘッダ、空欄上書き、ID空欄の新規採番、member_order の昇順反映。

UI：スマホ/PCのカード化とラベル、編集中保護、status→time/備考クリア。

認証：通常/スーパー管理者、ログオフ復帰、エラー経路のUI復旧。

互換：旧CSV・旧MENUSでの動作、ブラウザ差（Chrome/Edge/Safari/iOS/Android）。

10. 既存仕様のFAQ（抜粋・再掲）

CSVの表示順：member_order の数値昇順。行順は使いません。

出力時の表示順：常に 1..n に連番で再採番されます。

0/空欄の member_order を取り込んだ場合：その行は 無視（既存データは消えない/更新されない）。

id が空欄の新規メンバー：名簿に追加され、再取得後に IDが採番。在席データは初期値。

グループ名が1行だけ記入で他は空欄：現行は 最後に読んだ値が採用（空白で上書きの可能性あり）。運用で全行に同名を推奨（将来改善予定）。
```
