# 「共有」と「詳細な共有」

- 共有
	- 設定したフォルダまでの全階層が、「ネットワーク」で共有される
		- ドキュメントフォルダを共有した場合、コンピュータ名/users/ユーザー名/documents、と階層が共有されている
- 詳細な共有
	- 設定したフォルダだけが、「ネットワーク」で共有される
		- ドキュメントフォルダを共有した場合、コンピュータ名/documents、と共有されている

## どちらを使うべきか

- 基本的に、「詳細な共有」だけで良い
	- 「詳細な共有」を設定すれば、自然と「共有」内も設定される
	- 「共有」で設定しても、「詳細な共有」内の設定は行われない
	- 「共有」で一度設定すると、同じ画面から解除できない為下記を使用する必要がある
		- 「コンピューターの管理」→「システムツール」→「共有フォルダー」→「共有」　共有名を選び、「共有の停止」を行う
		- 管理者権限のコマンドプロンプトで下記のコマンドを使用する
            
			# 関連するコマンドプロンプト
            
			|   |   |
			|---|---|
			|net share|現在の共有一覧を表示する|
			|net share 共有名 /delete|共有を解除する  <br>※管理者権限が必要|
            

# 留意点

- 「共有」と「詳細な共有」の両方が有効だと、アドレスは「詳細な共有」の短いものが有効になるが、アクセス権は「共有」でも権限を持っている必要がある為、「詳細な共有」のアクセス許可だけ設定しても使用できない
